# ERAU Dining Times 🍔

A lightweight, mobile-friendly web app that shows real-time hours and operational status for dining spots around the Embry-Riddle Aeronautical University Daytona Beach campus. This project started out as a simple desktop Python tray app and got rewritten into a responsive web interface so I could actually check it on my phone.

Check it out live at: [https://hariguir.github.io/eraudiningtimes/](https://hariguir.github.io/eraudiningtimes/)

## Features
* **Live Status:** See immediately which campus spots are currently open or closed.
* **Smart Countdowns:** Displays how long until a location closes, or a color-coded countdown for when closed spots open back up (auto-sorted so the ones opening soonest stay at the top).
* **Phone-Friendly:** Styled with Tailwind CSS so it feels like a native mobile app.
* **No Bloat:** Built as a single-file implementation with zero heavy dependencies, so it's pretty fast.

## How to add it to your iPhone
1. Open the site in Safari (using the link above).
2. Tap the **Share** button in the bottom toolbar.
3. Scroll down and tap **"Add to Home Screen"**.
4. Open it right from your home screen whenever you need a quick check!

## !! **NOTE** !!
This is a static web page and does not account for special hours. Visit [the official site](https://eraudining.sodexomyway.com/en-us/locations/hours) for up-to-date information.
